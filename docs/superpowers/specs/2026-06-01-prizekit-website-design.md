# Сайт Приз_КитБот — дизайн-спецификация

**Дата:** 2026-06-01
**Статус:** утверждён (главная, карта сайта, стек и рандомайзер согласованы клиентом)

## Цель

SEO-портал про бота розыгрышей **Приз_КитБот** для мессенджера MAX — по образцу
конкурента [randocat.ru](https://randocat.ru). Сайт ловит трафик из поиска
(Гугл/Яндекс) по запросам про розыгрыши и конкурсы в MAX и превращает посетителя
в пользователя бота.

**Сейчас** сайт целиком про один бот (Приз_КитБот). Архитектура закладывается так,
чтобы позже без переделки добавить ещё 3 бота (отдельные продуктовые страницы +
переключатель в шапке + блок «Экосистема»).

## Что умеет бот (фактура для текстов)

- Создание розыгрыша через веб-форму (мини-приложение MAX): текст, фото/видео,
  кнопка участия, сроки.
- Условие завершения: по дате **или** по числу участников; любое число победителей.
- Проверка подписки на каналы-спонсоры; мультиканальные розыгрыши (организатор +
  партнёры/спонсоры); приватные каналы.
- Антибот, запрет участия админам, реферальная система (доп. билеты за друзей).
- Честный случайный выбор победителя, переразыгрыш, досрочное завершение.
- Уведомления участникам, экспорт, статистика приходов/отписок.

Готовый контент для переиспользования (в репозитории бота `raffle_bot/webapp/docs/`):
- FAQ — `faq.html`
- Договор оферты — `offer.html`

## Технический подход

**Astro** (генератор статических сайтов).

Причина: цель — SEO, значит каждая страница должна отдаваться поисковику как готовый
HTML с текстом. Astro собирает настоящий статичный HTML на каждую страницу (отличная
индексация), статьи блога пишутся одним файлом Markdown, а шапка/футер/дизайн живут
в одном месте. Результат сборки — папка статичных файлов, которую можно положить
куда угодно.

Рассмотренные альтернативы:
- **Чистый HTML/CSS вручную** — отклонено: десятки SEO-статей вручную нечитаемо
  поддерживать, дублирование шапки/футера.
- **React-SPA как у randocat** — отклонено: SEO слабее без пред-рендера, сложнее
  в поддержке для нетехнического владельца.

**Хостинг:** на первом этапе — GitHub Pages (бесплатно, авто-публикация из
репозитория). Позже — перенос на домен/VPS (Timeweb). Поскольку сборка статична,
перенос тривиален.

**Дизайн/бренд:** логотип — аватарка бота Приз_КитБот; фирменные цвета берём из неё
(клиент пришлёт файл аватарки на этапе вёрстки). Стилистика — чистая, светлая,
с акцентным фирменным цветом, мобильная адаптация (как у randocat).

## Структура главной страницы (блок за блоком)

1. **Шапка** — лого + меню (Как это работает · Рандомайзер · Тарифы · FAQ) +
   кнопка «Открыть бота». *Задел: переключатель продуктов — скрыт до появления
   остальных ботов.*
2. **Hero** — крупный заголовок «Розыгрыши и конкурсы в MAX — бесплатно»,
   подзаголовок про честный выбор и рост канала, кнопка «Запустить розыгрыш» → бот.
3. **«Что вы получите»** — 3 карточки: *Честный розыгрыш* (рандом + проверка
   подписки), *Рост канала* (рефералы, мультиканальные розыгрыши), *Полный контроль*
   (антибот, переразыгрыш, любое число победителей).
4. **«Как подключить за 3 шага»** — Напишите боту → Добавьте в админы канала →
   Создайте розыгрыш.
5. **«Как это работает»** — 4 шага с иконками (создаёте → пост публикуется → люди
   участвуют → бот выбирает победителя). Кнопка «Подробная инструкция» → /how-it-works.
6. **Возможности** — антибот, реф-система, приватные каналы, фото/видео, экспорт,
   статистика подписок, переразыгрыш.
7. **Блок-приманка «Бесплатный рандомайзер»** — мини-промо → /randomizer.
8. **FAQ-аккордеон** — 8–10 вопросов под поисковые запросы (из готового FAQ).
9. **Финальный призыв** — «Проведите первый розыгрыш за 2 минуты» + кнопка.
10. **Футер** — ссылки на все страницы, юр. документы, ссылка на бота.
    *Задел: блок «Другие наши боты — скоро».*

## Бесплатный рандомайзер (фаза 1)

Отдельная страница `/randomizer` с простым инструментом: пользователь вставляет
список участников (по строкам), задаёт число победителей, жмёт кнопку — получает
случайных победителей. Работает целиком в браузере (без сервера). Цель — ловить
поисковый трафик «генератор победителей / рандомайзер онлайн» и вести его к боту.

## Компоненты (переиспользуемые единицы)

- `Header` — шапка с навигацией и CTA (с заделом под переключатель продуктов).
- `Footer` — футер со ссылками (с заделом под блок «другие боты»).
- `Hero`, `FeatureCards`, `Steps`, `FeatureList`, `FaqAccordion`, `CtaBanner` —
  секции главной, переиспользуются на других страницах.
- `BaseLayout` — общий каркас (шапка + футер + SEO-мета через head).
- `BlogLayout` — каркас статьи блога (Markdown → HTML).
- `Randomizer` — клиентский виджет рандомайзера.

Каждый компонент имеет одну задачу, принимает данные через свойства (props) и
тестируется/меняется независимо.

## SEO

- Уникальные `<title>` и `<meta description>` на каждую страницу.
- Семантическая разметка (h1/h2/h3), Open Graph для красивых ссылок.
- `sitemap.xml` и `robots.txt` (Astro генерирует автоматически).
- Человекочитаемые ЧПУ-адреса (`/blog/rozygrysh-v-max`).
- Блог — основной источник органического трафика.

## Вне рамок (сейчас не делаем)

- Страницы остальных 3 ботов (только архитектурный задел).
- Платные тарифы и приём оплаты (страница `/pricing` — заглушка «бесплатно»).
- Личный кабинет / любая авторизация на сайте (всё действие — в боте MAX).
- Перенос на собственный домен/VPS (отдельный шаг после GitHub Pages).

## Открытые вопросы (не блокируют старт)

- Точные фирменные цвета — из аватарки бота (файл от клиента на этапе вёрстки).
- Финальные тексты SEO-статей — пишутся при наполнении блога.
