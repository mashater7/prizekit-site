Политика конфиденциальности

Обработка данных пользователей сервиса Приз_КитБот

1. Какие данные обрабатываются

Для работы розыгрышей сервис обрабатывает технические данные, предоставляемые мессенджером MAX: идентификатор и отображаемое имя пользователя, данные о подключённых каналах и факт участия в розыгрыше. Данные банковских карт сервис не хранит — оплата проходит через платёжную систему Robokassa.

2. Цели обработки

  • проведение розыгрышей и проверка выполнения их условий;
  • определение и оповещение победителей;
  • работа сервиса и связь с пользователем.

3. Передача третьим лицам

Данные не передаются третьим лицам, за исключением случаев, предусмотренных законодательством Российской Федерации, и сервисов, необходимых для работы (платёжная система, инфраструктура мессенджера MAX).

4. Контакты

По вопросам обработки данных: contact.kitbot@mail.ru.
